AUTH

认证与 CSRF

所有写操作都需要登录会话，并携带 CSRF Token。推荐流程：

  1. GET /api/v1/csrf/ 获取 Token，同时服务端会写入 csrftoken Cookie。
  2. POST /api/v1/auth/login/，请求体为 {"username":"<你的用户名>","password":"<你的密码>"}。
  3. 后续写请求带上请求头 X-CSRFToken: <token>，并保持同一会话 Cookie。
curl -c cookies.txt http://127.0.0.1:8000/api/v1/csrf/

curl -b cookies.txt -c cookies.txt -X POST \
  -H "Content-Type: application/json" \
  -H "X-CSRFToken: <token>" \
  -d '{"username":"<你的用户名>","password":"<你的密码>"}' \
  http://127.0.0.1:8000/api/v1/auth/login/

PLANS

计划

6 个端点
方法路径说明权限
GET/api/v1/plans/计划列表；支持 q、tag、category、sort、page按可见性
POST/api/v1/plans/创建计划登录
GET/api/v1/plans/{id}/计划详情按可见性
PUT/api/v1/plans/{id}/修改计划（支持部分字段）发起人 / 站务
DELETE/api/v1/plans/{id}/删除计划及其打卡发起人 / 站务
GET/api/v1/plans/{id}/checkins/该计划的打卡分页列表按可见性
 
POST /api/v1/plans/
{
  "title": "21 天高数冲刺",
  "summary": "每天 90 分钟，重点攻克极限与级数",
  "category": "exam",
  "tags": ["考研", "高数"],
  "start_date": "2026-11-26",
  "end_date": "2026-12-16",
  "daily_target": 90,
  "visibility": "public"
}
